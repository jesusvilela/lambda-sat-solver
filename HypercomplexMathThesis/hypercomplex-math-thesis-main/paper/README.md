# Paper Build

This directory contains the LaTeX/Tectonic thesis build.

## Build

From the repository root:

```powershell
tectonic paper/hypercomplex_math_thesis.tex
```

Expected output:

```text
paper/hypercomplex_math_thesis.pdf
```

The PDF is intentionally generated from self-contained LaTeX/TikZ/PGFPlots source so the figures remain inspectable and versionable.
