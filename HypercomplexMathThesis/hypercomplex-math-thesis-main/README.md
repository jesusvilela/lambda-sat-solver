## Tooling first: clone your GitHub repositories with `gh`

If you want to list and clone **private** repositories, authenticate first:

```bash
gh auth login
```

Then clone all private repositories for `jesusvilela` (Linux/macOS):

```bash
gh repo list jesusvilela --visibility private --limit 100 --json nameWithOwner -q '.[].nameWithOwner' | xargs -I {} gh repo clone {}
```

PowerShell variant:

```powershell
gh repo list jesusvilela --visibility private --limit 100 --json nameWithOwner --jq '.[].nameWithOwner' | ForEach-Object { gh repo clone $_ }
```

If you want **all repositories** (public + private), remove `--visibility private`.

## Jointed knowledge principle (hypercomplex tower)

> **To solve a problem, enter its geometry, resonate with its constraints, return through a symmetry, and enrich the world with the transformed result.**

A hypercomplex learning tower treats problem-solving as structural coupling:

1. Enter the problem deeply.
2. Preserve identity (do not dissolve).
3. Lift to richer representation spaces.
4. Return with a usable, shareable artifact.

Without return:

\[
\text{resonance} \rightarrow \text{absorption}
\]

With return:

\[
\text{resonance} \rightarrow \text{transformation} \rightarrow \text{knowledge}
\]

Formal flow:

\[
P_0
\xrightarrow{\text{immersion}}
P^*
\xrightarrow{\text{hypercomplex lift}}
\widetilde{P}
\xrightarrow{\text{symmetry / rotation}}
\widetilde{S}
\xrightarrow{\text{projection}}
S_0
\]

Where:

- \(P_0\): original problem.
- \(P^*\): problem as lived from inside.
- \(\widetilde{P}\): lifted hypercomplex representation.
- \(\widetilde{S}\): transformed solution space.
- \(S_0\): usable answer returned to ordinary life.

Human operational floors:

1. **Embodiment**: feel the problem from within (ecological, social, mathematical, emotional, technical).
2. **Geometry**: map constraints, attractors, symmetries, bottlenecks, curvature.
3. **Hypercomplex lift**: allow incompatible views to coexist (real, complex, quaternionic, octonionic, symbolic, narrative, empirical).
4. **Return/compression**: produce a usable output (proof, design, policy, experiment, medicine, story, protocol).

Grounding operator:

\[
\mathcal{G}_{\text{GROUND}} : \widetilde{S} \rightarrow S_{\text{usable}}
\]

Without grounding, theory becomes cosmic music.
With grounding, theory becomes civilization.
