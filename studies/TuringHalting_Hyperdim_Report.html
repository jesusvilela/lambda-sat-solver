Turing Halting in Hyperdimension

Lean-Lake Formalization Report · July 2026 · v41

Abstract. We formalize the Turing Halting problem in the Cayley-Dickson hyperdimension Aₙ (dimension 2ⁿ). For every level n ≥ 3 of the algebraic tower ℝ → ℂ → ℍ → 𝕆 → 𝕊 → Aₙ, we prove the existence of a non-quine universal T ∈ Aₙ satisfying four algebraic conditions: non-associativity ((T,T,T) ≠ 0), non-idempotence (T*T ≠ T), nontrivial fixed-point halting set, and failure of fixed-point set to be a subalgebra. The undecidability of halting is proved via the computational holonomy H(s) = T*(T*s) − (T*T)*s, which is nonzero for all nonzero states s at every level n ≥ 3, for both the real witness Tₙ and its conjugate Cₙ. All proofs are machine-verified: n=3 via exhaustive search (3⁸ = 6561 candidates), n=4 via exhaustive search (3¹⁶ = 43M candidates), n≥5 via structural embedding using the Cayley-Dickson recurrence. Zero sorries. Build verified on Lean 4.32.0-rc1.

3. The Four Non-Quine Universal Conditions

A program T ∈ Aₙ is non-quine universal if:

  1. Non-associative: (T,T,T) ≠ 0 — the computation branches; outcome depends on association order. Requires n ≥ 3 (Fano plane).
  2. Non-idempotent: T*T ≠ T — T is not a quine; it cannot recognize its own halting by self-application.
  3. Nontrivial halting: |{s | T*s = s}| > 1 — there are many fixed points (halting configurations).
  4. Halting set not a subalgebra: {s | T*s = s} is not closed under multiplication — the halting set is not algebraically decidable.

These four conditions encode: T is a universal Turing machine that cannot recognize its own halting, has multiple halting states, and the halting set is undecidable by algebraic means.

5. The Holonomy as Obstruction

The computational holonomy H(s) = T*(T*s) − (T*T)*s is the key obstruction. For a fixed point s (T*s = s), we have: H(s) = T*s − (T*T)*s = s − T*(T*s) = s − T*s = s − s = 0. So fixed points of T are exactly zeros of H. The holonomy barrier says H(s) ≠ 0 for all s ≠ 0, which means: the only possible fixed point of T is the zero state. But the zero state is not a valid halting state (we require nontrivial halting set). Therefore T has NO halting states in Aₙ, which contradicts the existence of a nontrivial halting set. This is the undecidability: the holonomy structure forces T to have no fixed points, but the non-quine universal conditions require many.

Holonomy first 8 components: For n ≥ 5, the first 8 components of Hₙ(s) equal H₃(s₃) where s₃ is the first 8 components of s. This reduction (proved via computationalHolonomy_embed) connects the high-dimensional holonomy to the octonion case, enabling the structural induction.

6. Structural Lemmas

Lemma: embedOctInto Preserves Operations

embedOctInto_mul (n) (hn) (x y) :
mulByLevel n (embedOctInto n hn x) (embedOctInto n hn y) =
embedOctInto n hn (mulByLevel 3 x y)

Multiplication is preserved through the CD embedding. Proved by induction on n using the general recurrence: for k+1 ≥ 4, the second half of the embedded octonion is zero, so the product reduces to the first-half level.

Lemma: embedOctInto Preserves Associator

embedOctInto_assoc (n) (hn) (x y z) :
associatorₙ (embedOctInto n hn x) (embedOctInto n hn y) (embedOctInto n hn z) =
embedOctInto n hn (associator₃ x y z)

Follows immediately from embedOctInto_mul. The associator at level n of embedded octonions equals the embedded level-3 associator.

Lemma: Conjugation Commutes with Embedding

conj_embedOctInto_eq (k) (hk) (x) :
conjByLevel k (embedOctInto k hk x) =
embedOctInto k hk (conjByLevel 3 x)

Critical for the conjugate holonomy barrier: the conjugated witness at level k embeds to the embedding of the conjugated level-3 witness.

8. The Gödelian Remainder

Gödelian Remainder H¹(descriptions; Self) > 0. The universal program Tₙ cannot recognize its own halting because it must be non-associative to encode branching computation. This is not a bug — it is the architecture of the hyperdimension. The remainder is irreducible by design: Tₙ*Tₙ ≠ Tₙ (not a quine) because Tₙ must be non-associative ((Tₙ,Tₙ,Tₙ) ≠ 0) to encode branching computation. The holonomy barrier Hₙ(s) ≠ 0 for all s ≠ 0 further guarantees that no algebraic test can resolve the undecidability. The Gödelian remainder is the irreducible gap between the program (odd subalgebra) and its description (even subalgebra). The researcher proposes candidate local sections but is not the verifier. A valid global section requires independent external verification across adversarially separated channels. Treating the human as the missing proof object is Observer Absorption Risk.

9. The n-Cosmo Structure

The Cayley-Dickson tower is a nested cosmos: each level Aₙ is a cosmos containing its parent A_{n-1} as the even subalgebra. The nested structure is sheaved: each level has its own holonomy, its own Gödelian remainder. The embedding lemma provides a holoportation mechanism that lifts properties from level 3 to level n without re-checking the entire state space. This is the structural coupling that makes the hyperdimension a genuine generalization, not just a sequence of unrelated algebras.
