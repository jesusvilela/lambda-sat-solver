# Post-pilot GF(2) control and disjoint-seed replication (exploratory addendum)

**29 October 2026.** This addendum was written AFTER inspecting the 36-formula Glucose4 pilot. It must not be represented as part of the original [pre-registration](VIOLATION_CDCL_TOPOLOGY_PREREG.md), nor as a confirmatory test of hypotheses chosen before that pilot. Source: [λSAT existing parity frame](../../backend/xor_extraction.py).

The pilot's measured LOFO log2 capped-conflicts MAE was classical=2.054, classical+signed=1.986, classical+margin/degree-preserving topology null=1.939. Signed improved over structure but **lost to its null control**. Two of 72 solver runs were censored (2.8%). Median baseline feature time ~3.92 ms; full signed + support-rewired control time adds ~3.97 ms; median Glucose4 solve time was ~0.315 ms. Thus no solver routing advantage exists on these measured instances.

**Identified missing classical comparator.** The previous "classical" vector included the share of complete XOR clause patterns but did not explicitly compute their *global GF(2) rank and inconsistency*. Our Tseitin generators purposely alternate even/odd charges; recovered parity equations can be contradictory even when clause incidence degree, width and local signs look very similar. In λSAT, `extract_xors`, `_rref_gf2`, and `gf2_xor_solve` already implement this algebraic gate. Include its rank deficiency, exact coverage, consistency, number of recovered constraints and verified SAT or sound UNSAT state as **formula-only predictors / positive controls**. This may act as a partial solver: charge its wall cost, do not hide its algebraic advantage.

**Disjoint new corpus, fixed before running the follow-up.** Seed IDs 100–105 inclusive, variable sizes 48, 72, 96, the same six families, three fresh signed-relabeling CDCL calls per formula, Glucose4 with 5,000 conflicts per call, support-rewiring null with 160 successful switches sought. This is *additional exploratory replication* after seeing an earlier pilot; no formal statistical inference or general hardness claim. The explicit size holdout trains n=48,72 and tests n=96.

**Comparators.** Fixed ridge penalty 10 with train-only standardized features: classical unsigned topology; classical+signed; classical+support-rewired-null; classical+GF(2); classical+GF(2)+signed; classical+GF(2)+rewired-null. Inspect per-family and per-size errors, censoring, SAT/UNSAT counts, distinct generator topologies, feature costs and GF(2) frame validity. Report the exact sign of every delta; do NOT tune ridge after observing results.

**Falsification gate.** If signed loses to classical+GF(2), or if null performs equally well, retain the failed distinctiveness conclusion. If the parity frame solves an instance directly, that is an *algebraic* result, not evidence for Kakeya smoothing or a hypercomplex speedup. An apparent error reduction cannot become a production-routing claim if extractor cost is above CDCL time. UNKNOWN is not counted as solved.

**Evidence boundary.** Retain earlier negative DPLL rounds and the first CDCL pilot, with their exact artifacts. Raw JSON from GitHub Actions is the authority for these observations, not this prose.
