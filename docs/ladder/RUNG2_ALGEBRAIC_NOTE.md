# Rung 2, algebraic face — the zero-divisor obstruction, made executable

**This note lifts the operator's "zero divisor = rank deficiency =
directional collapse" insight into a computable intrinsic invariant and
shows it is the algebraic sibling of the resolution refutation width from
`RUNG2_REPORT.md`.** Where Rung 2 named the sheaf-obstruction as *bounded
resolution width* (local sections that cannot glue), this note names its
algebraic twin: the **Nullstellensatz / Polynomial-Calculus degree over
GF(2)** — the least degree at which the constant `1` becomes reachable in
the span of the clause-violation polynomials, i.e. the least degree at
which the generators stop being rank-deficient with respect to `1`.

## The reframe (the operator's, and it is exactly right)

Encode each clause `C` by its **violation polynomial** over GF(2):

    v_C(x) = PROD_{literal l in C} (1 - l)

which is `1` on the single assignment that falsifies `C` and `0`
everywhere else (reducing `x_i^2 = x_i`). The CNF is UNSAT **iff** the
constant `1` lies in the ideal generated by `{v_C}` and the Boolean axioms
— iff `SUM_C g_C · v_C = 1` for some polynomials `g_C`. The **NS degree**
is the least `d` admitting a certificate with `deg(g_C · v_C) ≤ d`.
Equivalently: the least `d` at which `1` lies in the **GF(2)-linear span**
of `{ monomial · v_C : degree ≤ d }`. Below that `d`, the span is a proper
subspace missing `1` — a **cokernel / rank deficiency** of the degree-`d`
multiply-and-add operator `M_d`. That is precisely "the generators
collapse into a subspace and cannot reach the target": a zero-divisor /
directional-collapse obstruction, computed exactly.

## What was built

`backend.complexity.invariants.nullstellensatz_degree(formula, dmax, max_vars)`
— returns the integer NS degree of an UNSAT formula, `None` if satisfiable
(no certificate at any degree), `0` if an empty clause is present. It
builds, at each `d`, a GF(2) row-echelon basis of the degree-`d` generator
space (monomials as bitmasks, addition as symmetric difference) and tests
whether `1` reduces to `0`. Solver-independent, intrinsic, exact.

Validated (6 tests in `test_invariants.py`):

| formula | NS degree | resolution width | note |
|---|---|---|---|
| x₁ ; ¬x₁ | 1 | 1 | unit contradiction |
| implication chain (3 vars) | 2 | 2 | siblings agree |
| PHP(3→2), 6 vars | **4** | **2** | **siblings separate** |
| (x₁∨x₂) — SAT | None | None | no certificate exists |
| empty clause | 0 | 0 | already refuted |

## They track — and they are *not* the same object

The point of lifting the zero-divisor insight to its own invariant is that
it must carry information width does not, or it is decoration. It does:

- **Scaling families track.** Implication chains: width stays 2, NS degree
  climbs 2 → 3 as the chain lengthens. Both are monotone obstruction
  levels of the same instances.
- **NS degree ≥ width on every instance tested**, and **PHP separates them
  cleanly**: PHP(3→2) has all-width-2 clauses (resolution width 2) yet
  **NS degree 4**. This is the theoretically expected gap — the
  pigeonhole principle is the canonical family where the algebraic degree
  obstruction sits strictly above the resolution width obstruction. The
  zero-divisor lift is a genuinely distinct measurement, not a copy.
- **Homogeneous small random 3-SAT does *not* spread them.** On 40 UNSAT
  instances at n=8, α=5.5 (`docs/ladder/scripts/ns_degree_vs_width.py`),
  width is constant (3) and NS degree is near-constant (4, one 5). The
  reported Spearman ≈ 0.98 is driven by a single outlier and **should not
  be over-read** — at fixed (n, α) the random ensemble is too uniform to
  resolve either obstruction level. The honest signal is the *systematic
  offset* (NS ≈ width + 1 here, +2 on PHP), not a within-ensemble
  correlation.

## Why this is a hardness carrier (a theorem, same shape as width's)

NS/PC degree lower-bounds **Polynomial-Calculus refutation size**
(Clegg–Edmonds–Impagliazzo 1996; Impagliazzo–Pudlák–Sgall 1999) exactly as
Ben-Sasson–Wigderson width lower-bounds resolution size. So the algebraic
face is a real lower-bound instrument on its own proof system, not a
heuristic correlate — and PC can be *strictly stronger* than resolution on
families like PHP, which is why having both obstruction levels is worth
the cost.

## The honest limitation (same as its sibling, and the same point)

Exact NS degree is **exponential**: the degree-`d` generator count is
`O(m · nᵈ)` and the GF(2) elimination is on `2ⁿ` potential monomials, so
it is guarded by `dmax` and `max_vars ≤ 22`. Like `min_refutation_width`,
the *right* intrinsic object is genuinely hard to compute — which is again
why no cheap scalar off the incidence graph (Rung 1) can stand in for it.
The geometry (zero divisor → rank deficiency → cokernel of `M_d`) names the
obstruction exactly; it does not cheapen it. That congruence — the
operator's algebraic instinct landing precisely on the established
degree/rank lower-bound machinery — is the result.
