## Preregistration Rule

Before any future performance claim:

1. State claim;
2. State dataset;
3. State timeout;
4. State baselines;
5. State success criterion;
6. Run once;
7. Report pass/fail;
8. Do not tune post-hoc.

**Example valid claim:**
  "A stricter parity gate reduces OVERHEAD below HELP on the same
  20-instance SAT-2026 sample at T=10s."
  Criterion: HELP > OVERHEAD, correctness 0 wrong.

**Example invalid claim:**
  "Manifold weaving smooths hardness."
  Reason: no operator, no metric, no preregistered criterion.
