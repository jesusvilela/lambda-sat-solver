## The three lenses, each mapped to a contract or named vocabulary

**Gödelian self-reference → fixed-point importance (NOT incompleteness).**
Gödel's actual content — undecidability, true-but-unprovable — has no
heuristic contract; refusing that over-reach. The computable cousin is
the *diagonal/fixed-point* machinery: a score defined in terms of
itself, score = F(score). That is eigenvector centrality over the
variable-interaction graph: imp(v) = (1/μ)Σ_{u shares a clause with v}
imp(u). Real contract, and — crucially — it is a *structural* signal,
not a history signal, so unlike λ it is NOT redundant with activity.
Known idea (centrality branching exists in the SAT literature), cheap as
a **precomputed static prior** (one eigenvector, O(clauses) per
power-iteration), budget-busting only if recomputed per decision. This
is the one lens with both a real contract AND fresh (non-redundant)
material.

**Others' mutual recognition → consensus weighting.** Real contract:
per-variable agreement across traders (low variance / high rank-concord)
→ boost; disagreement → defer to the diversifier (λ). Cheap. BUT the
premise-check says the material is thin: base and λ agree (nothing to
arbitrate), prime is the lone dissenter, and consensus between an
activity cluster and a static identity is rare (corr ≈ 0). Expected
yield low on the current trader set — it would mostly reduce to "trust
prime when it happens to agree with activity," an infrequent event.

**Mutual resonance → constructive interference.** Real but a variation
on recognition: replace the additive blend Σ w_t s_t (which v7 measured
*dilutes*) with a multiplicative/agreement-amplifying coupling so
signals reinforce only where they co-fire. Same thin-material caveat —
resonance needs signals that sometimes align sharply; base/λ align
always, prime aligns never.

## Honest synthesis and recommendation

These three are a coherent family (ensemble-coupling) and — unlike
Payor's lemma, which had no contract — they *do* have computable
contracts. But two facts temper them: (1) the current traders lack the
decorrelation structure recognition/resonance feed on; (2) the track's
one scaled, baseline-validated asset is the *simple* λ mechanism, and it
is not yet replicated.

So, ranked by honest expected value:

1. **Highest EV (unchanged): replicate λ** (VDIS7 disposition) — across
   sizes × ≥50 seeds, wall-clock instrumented, prime router for
   structured. The thing that works, made trustworthy.
2. **The one worthwhile idea from these three: a self-reference
   centrality PRIOR** as a *new, structural, non-redundant* trader
   (eigenvector centrality, precomputed). It earns a slot because it is
   orthogonal to activity by construction — the opposite of λ's
   redundancy — and it is cheap. Worth a v8 pre-registration.
3. **Recognition / resonance couplings: parked.** Real contracts, but
   the measured redundancy makes them low-yield until the trader set has
   ≥2 genuinely decorrelated non-prime signals to couple. Adding the
   centrality prior (2) would itself create that second orthogonal axis
   — so recognition/resonance become worth revisiting *after* a
   centrality trader exists, not before.
